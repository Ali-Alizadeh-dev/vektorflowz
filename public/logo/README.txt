NOTES
  • The ANIMATED flow SVG plays when used on a website: <img src="...animated.svg">,
    as a CSS background-image, inline in your HTML, or opened directly in a browser.
    It does NOT animate as a favicon (browsers force favicons static) or inside
    Office/image viewers — use the -static.svg or the PNG there.
  • SVG is resolution-independent — prefer it for the website logo and favicon.
  • The lockup SVGs use live text in "Space Grotesk". If that font isn't installed
    where the SVG is opened standalone, it falls back to a system sans. On your site,
    load Space Grotesk (Google Fonts) and it will match exactly — or set the wordmark
    as real HTML text next to vektorflowz-mark.svg.
  • Keep clear space around the mark of at least the width of the V's left stroke.
